## 交互清单

**弧形轮播**
- 鼠标拖动（带惯性衰减 + 自动吸附到整数卡位）
- 鼠标滚轮横向切换
- 左右箭头按钮 / 底部圆点直接跳转
- 方向键 ← → 切换，ESC 关闭灯箱
- 灯箱支持触摸左右滑动

**其他**
- 作品网格分类筛选（带淡入淡出）
- 滚动进度条 / 导航栏毛玻璃
- 图片悬停视差微位移
- IntersectionObserver 入场动画
- 完整键盘可达 + `focus-visible` 焦点环
- 尊重 `prefers-reduced-motion`（自动关闭动效）

## 图片优化说明

原始 12 张图共约 40MB（单张最大 8.3MB），经 Pillow 处理：

- EXIF 方向自动转正
- 等比缩放到最大边 1400px
- PNG → JPEG（quality 88, progressive），无透明通道时启用
- 超窄长图（如 220×2917 的分镜稿）保留原宽度单独重采样，避免过度缩小

最终 3.3MB，压缩约 8 倍。

## 部署

纯静态站点，把 `portfolio/` 整个目录传到任意静态托管即可（Vercel / Netlify / GitHub Pages / 对象存储）。

若要接入在线简历，把 `RESUME` 相关的 HTML 段落换成后端数据渲染即可，结构已按条目拆好。
